# AutoHotkey-V2-ULTRAKILL-Parry-VFX-and-SFX
A lightweight AutoHotkey v2 script that simulates a parry effect on your desktop. Pressing G triggers a quick, faint, semi-transparent white overlay that smoothly fades out to give instant visual hit feedback without stealing window focus or blocking mouse clicks. Download the zip file and run the .ahk file as administrator.
